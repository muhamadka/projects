# מתכנן מיזוג אוויר – בחירת מערכת למבנה (ישראל)

כלי לתכנון ראשוני של מערכת מיזוג אוויר. אפשר להשתמש בו בדפדפן או כאפליקציית אנדרואיד (ראו למטה). מזינים את **שטח המבנה, מספר החדרים, גובה התקרה**, מספר הקומות, האזור בארץ וסוג המבנה. הכלי מחשב עומסי קירור וחימום, מחלק אותם לחדרים וממליץ על מערכת עם חלופות:

| מערכת | מתי נבחרת (כלל תכנון בכלי) |
|---|---|
| **מזגנים עיליים** | מעט חדרים (עד 2), דירה קטנה (פחות מ-60 מ"ר), או תקרה נמוכה מ-2.60 מ' שלא מאפשרת תעלות |
| **מיני מרכזי** | דירה של 60–200 מ"ר בקומה אחת, עד ~20 קו"ט, תקרה שמאפשרת הנמכה. מסחר קטן עד 20 קו"ט ו-3 חללים |
| **Mini-VRF** | וילה או דירה גדולה (מעל 200 מ"ר), מבנה רב-קומתי, או עומס מעל 20 קו"ט |
| **VRF** | משרדים ומסחר עם הרבה חללים, עד ~400 קו"ט (בתוספת ERV/DOAS לאוויר צח) |
| **יחידות גג** | חללים פתוחים: מסחר, אולמות ייצור ומחסנים בטווח 60–500 קו"ט |
| **צ'ילר מקורר אוויר** | מעל ~400 קו"ט במבנים מסחריים, ומעל ~500 קו"ט בתעשייה |
| **צ'ילר מקורר מים** | מעל ~1,200 קו"ט |
| **אוופורטיבי** | חלופה למחסנים ולתעשייה באקלים יבש (נגב, ערבה, ירושלים), כשאין צורך בבקרה מדויקת |
| **CRAC** | חדר שרתים, בתצורת N+1 |

## הפעלה

```bash
# ממשק – פותחים את הקובץ בדפדפן (ללא התקנה)
xdg-open index.html      # או לחיצה כפולה

# בדיקות למנוע החישוב
node test/engine.test.js
```

אפשר להשתמש במנוע גם מקוד:

```js
const HVAC = require('./hvac-engine.js');
const r = HVAC.design({ buildingType: 'apartment', area: 120, rooms: 5, height: 2.7, region: 'coastal' });
console.log(r.recommended.name, r.loads.peakKw, r.recommended.equipment);
```

## אוויר צח

הכלי מחשב את ספיקת האוויר הצח הנדרשת:
- **מגורים:** לפי ASHRAE 62.2, כלומר 0.15 ל'/ש' למ"ר ועוד 3.5 ל'/ש' × (מספר חדרי השינה + 1).
- **שאר המבנים:** לפי ASHRAE 62.1, כלומר ל'/ש' לאדם ועוד ל'/ש' למ"ר.

הפתרון הנבחר משפיע ישירות על העומסים:

| מצב | השפעה על המערכת הראשית |
|---|---|
| ללא (חלונות) | במגורים – אין אוויר מכני. במבנה מסחרי – האוויר נספר כלא מטופל |
| מאוורר מסונן ללא השבה | כל עומס האוויר הצח עובר למזגן |
| ERV (ליבת אנטלפיה) | חוסך כ-75% מהעומס המוחשי וכ-65% מהכמוס |
| DOAS / FAHU עם גלגל השבה | עומס האוויר הצח עובר כולו ליחידה נפרדת, עם סליל של כ-30% מהעומס |

במצב **אוטומטי** הכלי בוחר:
- ERV במגורים ובמבנים מסחריים עד 4,000 מ"ק/ש'.
- DOAS במבנים מסחריים מעל 4,000 מ"ק/ש'.
- אוויר משלים בתעשייה.

לכל פתרון מוצגים גודל היחידות, העלות, האנרגיה המוחזרת, החיסכון השנתי והמותגים. בנוסף מוצגות הערות על סינון (G4+F7 בגלל אובך), מיקום היניקה, CO₂ ואוורור לפי דרישה (DCV), ועל הממ"ד.

## אפליקציית אנדרואיד

קובץ ההתקנה המוכן נמצא ב-`android/dist/hvac-designer.apk` (גרסה 1.1, כ-80KB). האפליקציה עובדת **ללא אינטרנט**, ונדרש Android 5.0 ומעלה.

**התקנה בטלפון:**
1. מורידים את הקובץ `hvac-designer.apk` לטלפון.
2. פותחים אותו מתוך "הורדות" / "קבצים".
3. מאשרים "התקנה ממקורות לא ידועים" עבור האפליקציה שממנה פתחתם את הקובץ (כרום / קבצים).
4. אם Play Protect מציג אזהרה: "פרטים נוספים" ← "להתקין בכל זאת". האזהרה מופיעה כי האפליקציה לא הגיעה מחנות Play.

**בנייה מחדש** (אובונטו, ללא Android Studio):
```bash
sudo apt-get install -y aapt dalvik-exchange zipalign apksigner android-sdk-platform-23 python3-pil
./android/build.sh
```
הסקריפט אורז את `index.html` ואת `hvac-engine.js` לתוך WebView נייטיבי.

מפתח החתימה (`android/keystore/`) לא נשמר ב-git. בנייה במחשב אחר יוצרת מפתח חדש, ואז יש להסיר את הגרסה הקודמת מהטלפון לפני התקנת הגרסה החדשה.

## שיטת החישוב

1. **גאומטריה**: מחשבים טביעת קומה (שטח חלקי מספר הקומות), היקף (בתוספת מקדם צורה 1.15), שטחי קיר, זיגוג וגג. גובה התקרה משפיע על שטח הקירות ועל נפח החדירות.
2. **עומסים** (שיטת בלוק, ASHRAE):
   - **מעטפת**: U×A×(ΔT + תוספת קרינה). התוספת היא 7K לקירות ו-18K לגג.
   - **זיגוג**: הולכה, ובנוסף קרינת שמש לפי SHGC.
   - **אנשים, תאורה וציוד**: לפי צפיפות שמוגדרת לכל סוג מבנה.
   - **אוויר צח וחדירות**: לפי ASHRAE 62.1 ולפי מספר החלפות האוויר בשעה, בחישוב הפרש אנטלפיות (מוחשי + כמוס).
   - **מקדם ביטחון**: 10%.
   - **אולמות גבוהים**: מעל 4 מ' ומעל 6 מ' מופעל מקדם ריבוד על עומס הגג.
3. **חלוקה לחדרים**: העומס מחולק לפי שטח, ומוכפל במקדם שיא חדר (1.3 במגורים, 1.2 במסחר). המקדם מבטא את ההבדלים בין כיווני החזיתות ובין שעות השיא של החדרים. במגורים "מספר חדרים" נספר לפי הספירה הישראלית, כלומר הסלון נחשב חדר.
4. **עומס בו-זמני**: עומס המבנה × מקדם בו-זמניות. לפיו נקבע גודל היחידה המרכזית.
5. **בחירת ציוד**: מקטלוג גדלים מקובלים בשוק:
   - עיליים: 1–3 כ"ס
   - מיני מרכזי: 2.5–7.5 כ"ס
   - Mini-VRF: 4–12HP
   - מודולי VRF: 8–32HP, ושילובים של עד 3 מודולים
   - יחידות גג: 5–60 TR
   - צ'ילרים: לפחות 2 יחידות מעל 250 קו"ט
6. **בדיקות הנדסיות**:
   - יחס חיבור ב-VRF (מומלץ 50%–130%)
   - ריכוז קרר בחדר הקטן לפי EN 378 (R410A, ‏0.44 ק"ג/מ"ק)
   - ממ"ד לפי הנחיות פיקוד העורף
   - התאמת היחידות לאקלים לח או חם מאוד (מעבים לפעולה ב-46°C–52°C)
   - צורך בחיבור תלת-פאזי
7. **כלכלה**:
   - עלות מותקנת: טווח ₪ לקו"ט לפי סוג המערכת
   - צריכה שנתית: לפי EER, שעות הפעלה שקולות לפי אזור וסוג מבנה, ומחיר החשמל (ברירת מחדל 0.64 ₪ לקוט"ש)

## רקע מהמחקר על השוק הישראלי

- **שחקנים מרכזיים**:
  - **תדיראן** ו**אלקטרה** (קבוצת אלקו) הם שני היצרנים הגדולים בשוק המזגנים הביתיים. לפי נתונים היסטוריים של גלובס, יחד הם החזיקו כ-70% מהשוק.
  - אחריהם: **טורנדו**, ומותגים בינלאומיים כמו Gree, LG, Samsung, Mitsubishi Electric, Daikin ו-Toshiba.
  - בסקר BDO של מתקינים (2024): 60% בחרו בתדיראן כמותג הטוב ביותר, 19% באלקטרה ו-10% בטורנדו.
- **מיני מרכזי**: הפתרון הנפוץ בדירות חדשות בישראל. לפי גלובס, דגמי מיני מרכזי מהווים יותר מרבע מהשוק.
- **VRF**:
  - תדיראן הרחיבה את המפעל בעפולה ומייצרת מערכות **TADIRAN VRF PRIME**, ומציגה את עצמה כיצרנית ה-VRF הראשונה בישראל.
  - לבתים פרטיים יש מערכות Mini-VRF, כמו **VRF BOX**.
  - VRF מאפשר טמפרטורה נפרדת בכל חדר, אבל יקר יותר ממיני מרכזי ודורש תכנון מקדים.
- **צ'ילרים ויחידות גג**: במבנים גדולים נפוצים Carrier, Trane, York, Daikin ו-Climaveneta, לצד יצרנים מקומיים.

## הסתייגות

זהו כלי לתכנון ראשוני, להיתכנות ולהשוואת חלופות. התפוקות, המחירים וסימוני ה"כ"ס" הם ערכים מקורבים ומשתנים בין יצרנים. לפני ביצוע נדרשים:

- חישוב עומסים מפורט חדר-חדר (HAP / TRACE / ASHRAE RTS)
- בחירת ציוד לפי קטלוג יצרן
- תכנון של מהנדס מיזוג אוויר
- התקנה על ידי טכנאי קירור מוסמך
